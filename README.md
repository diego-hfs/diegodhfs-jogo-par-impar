# diegodhfs-jogo-par-impar

# 🎮 Jogo Par ou Ímpar com Python + Docker

Projeto simples desenvolvido em Python utilizando Docker para executar o jogo em container.

---

# 📌 Sobre o Projeto

Este projeto consiste em um jogo de **Par ou Ímpar** executado via terminal.

O usuário escolhe:
- Par ou Ímpar
- Um número

O computador gera automaticamente outro número e o sistema verifica o vencedor.

O objetivo do projeto é praticar:
- Python
- Docker
- Containerização
- Criação de imagens Docker
- Execução de containers

---

# 🚀 Tecnologias Utilizadas

- Python 3
- Docker
